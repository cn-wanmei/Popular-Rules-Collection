# Icon System 3.0

正式图标生产层：

Service Catalog → Icon Identity → Base Asset → Role Binding → 7-style Renderer → QA → Review Sheets → Client Index → Immutable Release

七种固定风格：

1. Official
2. Gradient
3. Liquid Glass
4. Soft 3D
5. Minimal
6. Dark / Neon
7. Monochrome / Duotone

风格化只处理容器、材质、背景、光效和展示层，不重新发明真实品牌 Logo 的核心几何。

角色固定为：

service / strategy / client_policy / provider / category / country / region / special

稳定 Release 必须包含 Registry、Manifest、Alias Index、7 张 master-all、provider/role/category 审阅图、24/32/48px 可读性图、7 客户端索引、Review Manifest、QA/Gate 报告和 previous-good 引用。

未知许可证资产只能进入候选池，不能进入默认稳定发布。
