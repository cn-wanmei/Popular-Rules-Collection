# PRC Icon Library V4

当前图标体系采用 9 个主流开放图标设计语言 + 1 个品牌原生 / 官方优先层。

## 10 层
1. Official / Brand Native
2. Lucide
3. Tabler Icons
4. Phosphor
5. Material Symbols
6. Fluent UI System Icons
7. Heroicons
8. Remix Icon
9. Bootstrap Icons
10. Solar Icons

这些集合覆盖 outline、filled、multi-weight、rounded、企业化及高表现力等主要视觉方向；2026 年公开生态资料持续将这些库列为主流开放图标集合。

## 品牌图标原则

真实品牌图标优先保留，不使用九种 UI 图标风格重新绘制品牌 Logo。缺失品牌身份时使用 semantic fallback，仅用于视觉覆盖，不代表官方品牌标识。
