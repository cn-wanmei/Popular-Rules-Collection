# PRC Icon Engine — Current V4

Icon V4 Pointer → Service Index → Official / Style Fallback → Service Docs / UI


V4 的目标不是重绘品牌 Logo，而是在品牌身份与统一 UI 视觉之间建立安全的 fallback 层。

真实品牌身份继续复用当前 V3 已发布资产；缺失身份时使用项目自有的九种风格 semantic glyph。
